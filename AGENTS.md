# Инструкции для работы с проектом

- Перед началом работы изучите [CODEX.md](CODEX.md) и [README.md](README.md).
- Соблюдайте архитектурные ограничения, описанные в CODEX.md. Frontend обращается к Backend через REST API. Backend проверяет права записи, а браузерная сессия использует JWT в HttpOnly cookies и защиту CSRF. Обе таблицы Office используют общий загрузчик страниц API.
- Для проверок с миграциями и заполнением тестовыми данными используйте изолированную базу. Порядок запуска описан в README.md.
- Ограничивайте изменения поставленной задачей. Если требуется расширить её рамки, сначала согласуйте это с владельцем.
